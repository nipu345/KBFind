---
title: Remote Desktop Connections to Office and Lab Workstations
tags: [remote, network, desktop]
---
## Symptoms
- A user working from home cannot connect to their office computer with remote desktop.
- The connection fails with "the remote computer cannot be found," or connects and then disconnects.
- A student needs to run lab software that is only installed on campus computers.

## Cause
Remote desktop only works through the VPN, and the office computer must be turned on, awake, and enabled for remote access. Lab software is offered through the virtual lab service instead of direct connections to lab computers.

## Resolution
1. Connect to the VPN before starting the remote desktop connection.
2. Confirm the office computer is powered on and set never to sleep. Ask a coworker to turn it on if needed.
3. Use the computer's full name (for example, ENG-1234.campus.example.edu), not its IP address, since addresses can change.
4. Confirm the user's account is allowed to connect remotely to that computer.
5. Students who need lab software should use the virtual lab portal in a web browser instead of remote desktop.
6. If the connection still fails, submit a ticket with the computer name and the error message.
