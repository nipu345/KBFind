---
title: Spam Filter Quarantine Review and Message Release
tags: [email, security]
---
## Symptoms
- A user is expecting an email from an outside sender, such as a vendor invoice or a job offer, and it never arrives.
- The sender says the message was delivered without any bounce.

## Cause
The campus email filter holds messages it suspects are spam or phishing in a quarantine instead of delivering them. Messages with attachments, links to newly registered websites, or senders with poorly configured email domains are quarantined most often.

## Resolution
1. Check the user's junk folder first.
2. Have the user open the quarantine portal or the daily quarantine summary email and search for the sender.
3. If the message is legitimate, release it to the inbox. The user can also mark the sender as trusted.
4. Do not release messages that ask for passwords, payment changes, or gift cards; report them as phishing instead.
5. If messages from a trusted sender are repeatedly quarantined, collect a message header and escalate so the filter rules can be reviewed.
