title: External Display Detection and Projection Troubleshooting
tags: [hardware, classroom]
---
## Symptoms
- Laptop is plugged into a classroom projector or second monitor and nothing shows up.
- Screen shows "no signal," or the image is stretched, cut off, or mirrored when it should be extended.

## Cause
Wrong input selected on the display, a faulty adapter or cable, or the operating system has not detected the display.

## Resolution
1. Confirm the projector or monitor input matches the port in use (HDMI 1, HDMI 2, USB-C).
2. Press Windows+P (Windows) or open Displays settings (macOS) and choose Duplicate or Extend.
3. Unplug and reconnect the cable, then try a different adapter if one is available.
4. Set the resolution to the display's native resolution to fix stretching.
5. For classroom systems, use the room control panel to power-cycle the projector and log a classroom support ticket if the input still shows no signal.
