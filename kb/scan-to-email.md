---
title: Multifunction Printer Scan-to-Email Failures
tags: [printing, email, hardware]
---
## Symptoms
- Documents scanned on the copier never arrive in the user's inbox.
- The copier shows an error when sending a scan, or the scan arrives as an unreadable file.

## Cause
The copier sends scans through the campus mail relay. Scans fail when the copier's network connection drops, the file is larger than the attachment size limit, or the scan lands in the user's junk folder because it came from a device address.

## Resolution
1. Check the user's junk and quarantine folders for the scan.
2. Have the user confirm their email address is typed correctly or chosen from the address book.
3. Scan fewer pages at once, or lower the resolution, to stay under the 25 MB attachment limit.
4. Choose PDF as the file format so the scan opens on any device.
5. As an alternative, use scan-to-cloud-storage if it is set up on the copier.
6. If no scans from the copier arrive for anyone, log a ticket with the copier's asset tag so its network settings can be checked.
