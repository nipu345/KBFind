---
title: Operating System Update Installation Failures
tags: [desktop, software, security]
---
## Symptoms
- Updates download but fail to install, or the same update keeps trying to install.
- The computer shows a notice that it is out of compliance or will be restarted to finish updates.
- The update gets stuck at a percentage during restart.

## Cause
Updates fail when disk space is low, when the computer is never restarted to finish installing, when the battery is low or unplugged, or when the update cache is corrupted. Managed computers must stay on supported versions to keep network access.

## Resolution
1. Plug in the computer and confirm at least 20 GB of free disk space.
2. Restart the computer and check for updates again.
3. If an update is stuck during restart for more than an hour, hold the power button to turn it off and turn it back on; it will usually roll back and retry.
4. On Windows, run the built-in update troubleshooter. On macOS, install the update from the Software Update page instead of from a notification.
5. If the update still fails, record the error code and escalate so the device can be repaired remotely.
