---
title: Restoring Deleted or Overwritten Files from Version History
tags: [storage, desktop]
---
## Symptoms
- A user accidentally deleted an important file or folder.
- A document was saved over with the wrong content and the user needs yesterday's version.

## Cause
Files are often recoverable. Cloud storage keeps deleted files in a recycle bin and saves earlier versions of each file. Department shared drives keep nightly snapshots for a limited time.

## Resolution
1. For cloud storage, open the recycle bin on the storage website and restore the file. Deleted items are kept for 93 days.
2. To recover an earlier version, open the file's version history and restore the version from before the change.
3. For a shared drive, right-click the folder and use "Restore previous versions" to copy files from a snapshot.
4. For files only saved on the local computer, check the computer's recycle bin or trash.
5. If the file is not in any of these places, submit a restore request with the file name, location, and approximate date it was last correct. Backups are kept for 30 days.
