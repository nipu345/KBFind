---
title: Local Disk Space Exhaustion
tags: [desktop, storage]
---
## Symptoms
- The computer warns that the disk is almost full.
- Updates fail to install, applications crash when saving, or the computer becomes very slow.

## Cause
Large downloads, video files, old installers, and cloud files set to "always keep on this device" fill the internal drive. Once less than about 10% is free, the operating system cannot install updates or manage memory well.

## Resolution
1. Check which folders use the most space in the storage settings.
2. Empty the Downloads folder, trash, or recycle bin.
3. Set synced cloud folders to "free up space" so files are stored online and downloaded only when opened.
4. Run the built-in storage cleanup tool to remove temporary files and old update files.
5. Uninstall applications that are no longer used.
6. If the drive is full of necessary work files, move them to cloud storage or request a larger drive through a hardware ticket.
