---
title: Software License Activation and Seat Limit Errors
tags: [software, accounts]
---
## Symptoms
- An application says it is unlicensed, in trial mode, or that the license has expired.
- The user gets an error that the maximum number of activations has been reached.
- Specialized software works on campus but not at home.

## Cause
Campus-licensed software is activated by signing in with the university account, by a license key, or by contacting a campus license server. Licenses are limited to a set number of devices, and license server software only works on the campus network or VPN.

## Resolution
1. Have the user sign out of the application and sign back in with their university account, not a personal account.
2. If the activation limit is reached, sign out of the software on old computers, or remove old devices on the vendor's account page.
3. For license server software, connect to the VPN when off campus.
4. Confirm the user is eligible for the software; some titles are licensed only for specific departments or labs.
5. If the license still will not activate, submit a ticket with the application name, version, and error message.
