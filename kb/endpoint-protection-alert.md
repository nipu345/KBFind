---
title: Endpoint Protection Malware Alert Response
tags: [security, desktop]
---
## Symptoms
- The antivirus or endpoint protection software shows an alert that a threat was found, blocked, or quarantined.
- The user is unsure whether the computer is still safe to use.

## Cause
Endpoint protection blocks files and actions that match known malware or suspicious behavior. Many alerts are for blocked downloads or browser files that were stopped before running. Some are false positives on legitimate research or development tools.

## Resolution
1. Have the user note the threat name and file path from the alert, then take a screenshot.
2. If the alert says the threat was blocked or quarantined, no action is needed beyond reporting it.
3. If the alert says the threat could not be removed, disconnect the computer from the network and contact the security team right away.
4. If the user entered their password on a suspicious site around the same time, follow the credential compromise steps.
5. Do not restore quarantined files unless the security team confirms they are safe.
