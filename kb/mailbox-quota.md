---
title: Mailbox Storage Quota Exceeded
tags: [email, storage]
---
## Symptoms
- The user gets warnings that their mailbox is almost full.
- They can receive mail but cannot send, or outside senders get a "mailbox full" bounce.

## Cause
Each mailbox has a storage limit. Large attachments, years of Sent Items, and a Deleted Items folder that is never emptied are the usual reasons it fills up.

## Resolution
1. Have the user check current usage in the web mail settings page.
2. Sort the mailbox by size and delete or save off messages with large attachments.
3. Empty the Deleted Items folder and the Recoverable Items folder.
4. Turn on the online archive, which moves older mail out of the main mailbox automatically.
5. Save attachments to cloud storage and share links instead of sending files by email.
6. If the user still needs more space for a business reason, submit a quota increase request with manager approval.
