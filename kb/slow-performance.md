---
title: Endpoint Performance Degradation
tags: [desktop, hardware]
---
## Symptoms
- The computer takes a long time to start, opening applications is slow, or the fan runs constantly.
- The user describes it as "freezing" or "lagging," especially with many browser tabs open.

## Cause
Common causes are too many programs starting automatically, low free disk space, not enough memory for the workload, pending updates, or the computer not having been restarted in weeks. Less often, a failing drive or malware is the cause.

## Resolution
1. Restart the computer. Many slowdowns clear after a full restart, especially if it has been running for weeks.
2. Install pending operating system updates and restart again.
3. Check the task manager or activity monitor for programs using high CPU or memory.
4. Turn off unneeded startup programs.
5. Confirm at least 10% of the disk is free.
6. If the computer is more than five years old or has less than 8 GB of memory, check whether it is eligible for replacement.
7. If the slowdown appeared suddenly, run a full scan with the endpoint protection software.
