---
title: Fake Virus Warning and Tech Support Scam Pop-ups
tags: [security, browser]
---
## Symptoms
- A browser window suddenly fills the screen saying the computer is infected, often with a loud alarm.
- The page tells the user to call a phone number or download a "cleaner" tool.
- The window cannot be closed normally.

## Cause
These are scam web pages, usually reached through malicious ads or mistyped web addresses. They are not real virus alerts and cannot infect the computer on their own. The danger is calling the number or installing what they offer.

## Resolution
1. Tell the user not to call the number, install anything, or give anyone remote access.
2. Close the browser with Task Manager on Windows (Ctrl+Shift+Esc) or Force Quit on macOS (Cmd+Option+Esc).
3. When reopening the browser, do not restore the previous session.
4. Remove any unfamiliar browser extensions.
5. If the user already called the number, gave remote access, or paid, disconnect the computer from the network, change their password from another device, and report it to the security team.
