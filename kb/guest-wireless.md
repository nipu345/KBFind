---
title: Guest Wireless Access Provisioning for Visitors
tags: [network, wireless]
---
## Symptoms
- A visiting speaker, vendor, or family member needs internet access but has no campus account.
- The visitor connects to the guest network but is stuck on the sign-in page, or access stops working after a day.

## Cause
The secure campus network requires a campus account, so visitors must use the guest network. Guest access is granted through a self-registration page that sends a code by text message, and each code expires after 24 hours.

## Resolution
1. Have the visitor connect to the guest network, not the secure campus network.
2. Open a browser and visit any non-secure web address if the sign-in page does not appear on its own.
3. Enter a mobile number to receive a one-time access code.
4. For multi-day events, a staff sponsor can request a sponsored guest pass that lasts up to 7 days.
5. If no sign-in page appears at all, forget the network on the device, turn off private address randomization for the guest network only, and reconnect.
