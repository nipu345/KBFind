---
title: Software Installation Under Standard User Privileges
tags: [software, desktop]
---
## Symptoms
- User tries to install an application and is asked for an administrator name and password.
- Installer fails with "you do not have permission" or "access denied."

## Cause
Managed computers run with standard user accounts. Installing software system-wide requires elevated privileges, which are restricted to reduce malware risk.

## Resolution
1. Check the self-service software center; most approved applications install there without admin rights.
2. If the application is not listed, submit a software request so it can be reviewed for licensing and security.
3. For urgent course or research needs, a technician can perform a supervised install after approval.
4. Do not share or grant local administrator credentials to the user.
