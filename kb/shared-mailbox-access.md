---
title: Shared Mailbox Delegation and Access
tags: [email, accounts]
---
## Symptoms
- A staff member cannot see a department mailbox, such as an admissions or front-desk inbox, in their mail client.
- The user can read the shared mailbox but cannot send as it, or sent items land in their personal Sent folder.

## Cause
Access to a shared mailbox is granted by the mailbox owner and must be requested. "Full access" lets a user read the mailbox, and "send as" is a separate permission. New permissions can take up to an hour to appear in desktop mail clients.

## Resolution
1. Confirm the mailbox owner or department manager has approved access.
2. Grant full access and, if needed, send-as permission in the mail administration console.
3. Have the user fully close and reopen the mail client after an hour; the mailbox should appear automatically.
4. If it does not appear, add it manually under account settings as an additional mailbox, or open it in the web mail client.
5. To send from the shared address, the user must choose it in the From field of each message.
