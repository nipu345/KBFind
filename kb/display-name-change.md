---
title: Display Name and Preferred Name Updates
tags: [accounts, identity, email]
---
## Symptoms
- A user's email, directory listing, or class rosters show a name they no longer use.
- The user changed their preferred name, but some systems still show the old one.
- The user wants a new email address that matches their name.

## Cause
Names flow from the student or HR record into every connected system. A preferred name can be set without a legal name change, but each system picks up the change on its own sync schedule, which can take a few days.

## Resolution
1. Have the user set their preferred name in the student or employee self-service portal.
2. Allow up to 3 business days for the change to appear in email, the directory, and the learning management system.
3. Treat name change requests with privacy and do not ask why the user is changing their name.
4. A new email alias that matches the new name can be added on request. The old address keeps working so mail is not lost.
5. If a system still shows the old name after 3 days, submit a ticket listing the specific system where it appears.
