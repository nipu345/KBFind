---
title: Sending Sensitive Files Securely
tags: [security, storage, email]
---
## Symptoms
- A user needs to send documents with Social Security numbers, health information, or student records to someone.
- A file is too large to attach to an email.
- An outside partner needs to upload files to the university.

## Cause
Regular email is not approved for sensitive data and has a 25 MB attachment limit. The university provides cloud storage sharing and a secure file transfer service for these cases.

## Resolution
1. Do not attach sensitive data to regular email or upload it to personal file-sharing services.
2. For colleagues, share the file from university cloud storage with only the people who need it.
3. For outside recipients, use the secure file transfer service, which sends a link that expires and requires the recipient to verify their email.
4. To receive files from outside the university, create a secure upload request link in the file transfer service.
5. For large files without sensitive data, share a cloud storage link instead of attaching the file.
6. If sensitive data was sent the wrong way, report it to the security team so they can help limit exposure.
